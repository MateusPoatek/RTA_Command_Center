RTA Data Sources Reference

Where each field on the RTA Board and the attendance report comes from: GTT, the Workday columns GTT carries, the Verint RTA extension, or our own derivation. Each field lists its GTT column, a synthetic example, where the code parses it, and what it feeds. Generated 2026-10-09 from RTA_Board_V2/src/data/lineage.ts.

GTT cols 2–5 carry Workday → join on workdayId ← Verint (name only today, fuzzy) → Derived report + alerts
